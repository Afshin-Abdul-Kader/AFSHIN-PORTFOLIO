# Afshin Abdul Kader — Personal Portfolio

A polished full-stack developer portfolio prepared for internship and placement use.

## Stack
- React + Vite + JavaScript
- Node.js + Express
- PostgreSQL
- Responsive custom CSS
- Git / GitHub
- Vercel-ready frontend

## Included
- Premium responsive portfolio UI
- Smart Ledger, RoadGuard AI and Mini Games Hub
- DSA / LeetCode showcase
- Certifications
- GitHub, LinkedIn, LeetCode, Instagram, email and phone
- Working contact form wired to an Express + PostgreSQL API
- Validation, error handling and accessible UI
- SEO metadata and favicon
- Editable project-link data

## Run
```bash
npm install
npm run dev:client
```

In another terminal:
```bash
npm run dev:server
```

For the database:
```bash
npm run db:init
```

Set `DATABASE_URL` and `CORS_ORIGIN` in the server environment before database/API testing.

## Important
Real project URLs are intentionally blank in `client/src/data/site.js` until the actual deployed Mini Games link, Smart Ledger release/download link, and repository URLs are supplied. No fake links are published.
