# Portfolio Build — Final Stages 1–5

## Stage 1 — Foundation
React + Vite, reusable components, responsive CSS, accessible navigation, SEO metadata and a dark engineering-studio visual system.

## Stage 2 — Portfolio
Hero, Smart Ledger, RoadGuard AI, Mini Games Hub, skills, DSA/LeetCode, about and certifications.

## Stage 3 — Full Stack
Express API, PostgreSQL pool, health endpoint, contact message endpoint, CORS, environment variables and server-side validation.

## Stage 4 — Real Links
GitHub, LinkedIn, LeetCode, Instagram, email and phone are configured. Project action URLs remain blank until the real live game URL, Smart Ledger release URL and project repositories are supplied.

## Stage 5 — QA readiness
Responsive layouts, focus states, reduced-motion support, form validation, error/success states, SEO metadata, favicon and production build script are included.

### Final verification
Run:
```bash
npm install
npm run build
```
Then run the client and API separately for end-to-end contact testing.
